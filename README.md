# Ante Bellum - The Lost World - Modpack

## Description

This repository contains the modpack of submods of Ante Bellum - an EU4 mod:
- The Lost World
- Map Border Overhaul
- Ante Bellum Flavor
- Ante Bellum Mission Pack

## Scalenie z Victorum-Enhanced i grotaclas Bugfixes

To repo zawiera mechaniki z Victorum (v1.37 Vasco da Gama) dopasowane do mapy Ante Bellum oraz poprawki grotaclas Bugfixes.
Szczegóły, zasady rozstrzygania konfliktów i znane ryzyka: [docs/merge/MERGE_REPORT.md](docs/merge/MERGE_REPORT.md).
